# API Limit Policy

## Purpose

This policy specifies the API rate limits and request quotas.

## Allowed

- Quote the standard rate limits: 100 requests per minute.
- Explain how to check current usage headers.
- Suggest optimization strategies to reduce API calls.

## Restricted

- Do not manually increase API rate limits for individual keys.
- Do not disclose internal API endpoints.

## Escalation

Escalate requests for custom high-volume API quotas to the engineering team.
