# Security Compromise Runbook

## Purpose

This runbook outlines steps for suspected security breaches.

## Allowed

- Immediately lock the affected user account.
- Direct user to change password and re-enable MFA.
- Reassure customer that the security team is investigating.

## Restricted

- Do not share forensic audit logs with the customer.
- Do not admit liability or name external attack vectors.

## Escalation

All suspected compromises are critical and must be escalated to SecOps immediately.
